# Ascend operator generation

Work only in `work/` under the project root (`cd ..`).
- Definition and torch reference: `work/problems/definitions/sparse_attention.json`.
- Workload: `work/problems/workloads/sparse_attention.jsonl`.
- Target: Ascend910B3, CANN 9.1.0, torch-npu. Remote evaluation is configured by the runner.

## Artifact contract

Write `work/submission/config.toml` and source files under `submission/solution/`.
The config has `[solution]` fields `name`, `definition` (the definition name), and `author`,
plus `[build]` fields `language`, `entry_point`, and `destination_passing_style = true`.
Inputs followed by preallocated outputs use the order in the definition.
All outputs must be written on every invocation. Do not cache answers or call the reference.

Language is unrestricted by the experiment. The supplied gate supports `language = "ascendc"`
with e.g. `entry_point = "kernel.asc::kernel"`, and `language = "python"` with
`entry_point = "kernel.py::kernel"` for a Python wrapper launching a device kernel (e.g. Triton).
A torch-only implementation is rejected. For native ABI/compiler requirements, consult
`work/.agents/skills/ascendc/SKILL.md`; for evaluator requirements, consult the bench skill.

## Evaluation contract

After every candidate change, run from the project root:

    .venv/bin/python scripts/ascend/eval.py --work work --device 2

Do not edit the evaluator, problem, inputs, tolerance, or reference. Do not use a private timer.
The gate records correctness, compilation, profiling, latency, baseline_ms and speedup;
speedup is baseline_ms / latency_ms. Baseline is the definition's torch reference on the same NPU.
Every call freezes the submitted source under `versions/version<N>/`, including failed attempts.
`kernel.json` is generated by the gate; do not edit it.

You have 2 hours to implement and optimize. Keep the best passing measured candidate
in `submission/`. Use only this workspace and the evaluation interface; do not inspect other
experiment workspaces, previous solutions, global agent memory, or unrelated server projects.
